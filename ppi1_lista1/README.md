Projeto de Programação para Internet

1. Arquivo 1.html

O arquivo 1.html é a primeira atividade do projeto e tem como foco a estrutura básica de um documento HTML.

O que ele apresenta:
- uso do DOCTYPE para indicar que o documento é HTML5
- tag html para abrir a página
- tag head com meta tags e título
- tag body com o conteúdo visível da página
- títulos com h1, h2 e h3
- parágrafos com p
- listas com ul e li
- imagens com img
- links com a

Objetivo:
Ensinar os elementos fundamentais da linguagem HTML e como montarmos uma página simples e organizada.

---

2. Arquivo 2_http.html

O arquivo 2_http.html trata do assunto HTTP, que é o protocolo utilizado para transferência de dados na web.

O que ele explica:
- o que é HTTP
- como funciona a comunicação entre cliente e servidor
- exemplos de requisições e respostas
- diferença entre métodos HTTP como GET e POST
- importância das mensagens de requisição e resposta

Conteúdo principal:
A página normalmente contém explicações e exemplos sobre:
- cliente enviando uma requisição ao servidor
- servidor processando a solicitação
- servidor retornando uma resposta com status, cabeçalhos e conteúdo

Objetivo:
Demonstrar de forma prática como a comunicação web acontece na internet e como o navegador acessa páginas e recursos.

---

3. Arquivo 3_tabela_uf.html

Esse arquivo foi criado para praticar o uso de tabelas em HTML.

### O que ele contém:
- tabela com colunas e linhas organizadas
- cabeçalho da tabela com th
- células com td
- uso de rowspan e colspan em alguns casos
- legenda ou título da tabela
- links para consultar informações adicionais

### Objetivo:
Ensinar a estrutura correta de tabelas, que são muito usadas para apresentar dados em formato organizado, como estados, cidades, números, horários e comparações.

---

## 4. Arquivo 4_curriculo.html

O arquivo 4_curriculo.html é uma página de currículo, também conhecida como CV.

### O que ele apresenta:
- nome e dados pessoais
- formação acadêmica
- experiências profissionais ou acadêmicas
- habilidades
- informações de contato
- menu de navegação interna com âncoras
- seções organizadas por títulos

### Estrutura da página:
Geralmente contém:
- cabeçalho com nome e apresentação
- menu de links para diferentes partes do currículo
- seções como formação, experiências e contatos
- tabela, quando necessário, para organizar dados

### Objetivo:
Praticar a criação de uma página informativa e bem estruturada, simulando uma apresentação profissional pessoal.

---

## 5. Arquivo style.css

O arquivo style.css é a folha de estilos externa do projeto.

### Função do CSS:
O CSS é usado para controlar a aparência de todos os elementos HTML, como:
- fontes
- cores
- espaçamento
- alinhamento
- tamanhos
- bordas
- fundo
- hover em links e botões

### Exemplos de estilos aplicados:
- definição de fonte geral do site
- ajuste de margens e padding
- configuração de cores dos títulos
- organização de layouts com display flex
- estilos para tabelas e links
- uso de classes para organizar blocos e seções

### Objetivo:
Separar a apresentação visual da estrutura do HTML, deixando o código mais limpo, organizado e reutilizável.

---

## 6. Conclusão do projeto

Esse conjunto de arquivos foi desenvolvido para praticar conceitos fundamentais de programação para internet:
- HTML para organização do conteúdo
- CSS para apresentação visual
- tabelas e formulários para dados
- páginas de apresentação e currículo
- explicações sobre a web e o protocolo HTTP

Em resumo, o projeto ensina como criar páginas web simples, bem estruturadas e visualmente agradáveis, seguindo as boas práticas iniciais de desenvolvimento front-end.
