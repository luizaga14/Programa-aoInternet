Protocolo HTTP

O HTTP (Hypertext Transfer Protocol) é o protocolo usado para transferir páginas web, imagens, vídeos e outros recursos entre um cliente e um servidor. Quando você acessa um site no navegador, ele envia uma requisição HTTP para o servidor, que responde com o conteúdo solicitado.

Como o HTTP é usado na Web

O navegador envia uma mensagem de requisição ao servidor usando métodos como GET, POST, PUT e DELETE. O servidor interpreta a requisição e E devolve uma resposta HTTP com dados, páginas, arquivos ou mensagens de erro.

Exemplo de requisição HTTP

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html
Connection: keep-alive

Nesse exemplo, o cliente solicita a página /index.html no site www.exemplo.com. O navegador informa também o tipo de conteúdo que aceita.

Exemplo de resposta HTTP

HTTP/1.1 200 OK
Date: Wed, 30 Sep 2026 12:00:00 GMT
Server: Apache/2.4
Content-Type: text/html; charset=UTF-8
Content-Length: 1234

<html>
  <body>
    <h1>Olá, mundo!</h1>
  </body>
</html>

Principais campos de um Request

  • Method: indica a ação, como GET ou POST.
  • URL: endereço do recurso solicitado.
  • Host: nome do servidor.
  • User-Agent: informa o navegador ou cliente.
  • Accept: tipos de conteúdo aceitos pelo cliente.
  • Connection: controla a conexão com o servidor.

Principais campos de um Response

  • Status code: indica o resultado, como 200 OK ou 404 Not Found.
  • Date: data e hora da resposta.
  • Server: software do servidor.
  • Content-Type: tipo do conteúdo retornado.
  • Content-Length: tamanho do corpo da resposta.
  • Body: conteúdo da página ou arquivo.
